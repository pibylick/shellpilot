# ShellPilot MVP Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Dostarczyć działającą wtyczkę Zsh i lokalny klient Python dla dwóch terminali i dwóch lokalnych agentów.

**Architecture:** Cienka wtyczka Zsh przechwytuje metadane powłoki, uruchamia klienta i edytuje ZLE. Klient odczytuje kontekst przez adapter terminala, maskuje go, komunikuje się JSON z agentem i zapisuje sesję per panel/backend.

**Tech Stack:** Zsh 5.9+, Python 3.10+ stdlib, opcjonalny pakiet `iterm2`, `unittest`.

**Spec:** `SPECIFICATION.md`, `ARCHITECTURE.md`, `ROADMAP.md`.

## Global Constraints

- macOS; cmux i iTerm2 w MVP; Oh My Zsh opcjonalny.
- Lokalne Codex CLI i Claude Code, bez dodatkowego klucza API i bez instalowania agentów.
- Agent nie może wykonywać narzędzi ani komend; kandydat trafia do ZLE bez Enter.
- Scrollback to `combined`, rozdzielne stdout/stderr pozostają niedostępne.
- Brak wrappera PTY, dodatkowych paneli i automatycznego pobierania obcych paneli.
- Ta gałąź nie publikuje repozytorium ani nie dodaje licencji bez decyzji właściciela.

## Review Focus

- Obcy lub niepotwierdzony panel: klient odmawia pobrania kontekstu, nie czyta aktywnego panelu na zapas.
- Sekrety i sekwencje terminalowe: prompt po redakcji nie zawiera ich w czytelnej postaci.
- Przerwane lub błędne JSONL: błędna tura nie zapisuje sesji ani komendy.
- Nieznane narzędzie backendu: klient odmawia działania, nie polega na samym prompcie.
- ZLE po błędzie: bufor pozostaje bez zmian, a model nigdy nie wysyła Enter.
